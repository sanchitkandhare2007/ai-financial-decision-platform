About the Project

Objective

Help users understand basic loan eligibility, EMIs and credit scores, and get simple AI-based financial guidance.

Technologies

HTML5, CSS3, JavaScript, Node.js + Express, Anthropic Claude API, Google Sheets API.

Main Modules

Loan Eligibility, EMI Calculator, Credit Score Analyzer, AI Financial Tips, Records Dashboard.

Benefits

Explainable results, free to run locally, secure server-side API keys, privacy-friendly records.

Limitations

Uses simplified rules, not real bank policy or credit-bureau data. No login. AI answers can be imperfect.

Future Scope

Authentication, ML loan prediction, PDF reports, advanced credit-risk models, personalised dashboards, bank APIs, multilingual support, secure cloud database.

Privacy & Disclaimer

This platform does not collect names, PAN, Aadhaar or bank account details. Only the numbers you submit (income, age, score, loan details) are saved with a random anonymous session ID. All outputs are educational estimates and are not financial advice, a credit report or a loan approval.
